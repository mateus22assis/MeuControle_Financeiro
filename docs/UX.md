# UX — Fluxo de Navegação

## Objetivo

Este documento define a experiência de navegação da aplicação, descrevendo como o usuário interage com o sistema desde a abertura até o encerramento da sessão.

O objetivo é garantir uma navegação simples, intuitiva e consistente, reduzindo a quantidade de passos necessários para executar as operações mais frequentes.

A interface deverá priorizar a consulta da situação financeira antes da realização de novos lançamentos, mantendo o Dashboard como ponto central da aplicação.

Todas as funcionalidades deverão ser acessadas a partir do Dashboard e, sempre que possível, retornar a ele após sua execução.

## Princípios de Navegação

A experiência do usuário deverá seguir os seguintes princípios:

- O Dashboard será sempre a tela inicial.
- O Dashboard será também o ponto de retorno após a conclusão das operações.
- As funcionalidades deverão exigir o menor número possível de cliques.
- O usuário nunca deverá perder a percepção de onde está dentro da aplicação.
- Informações importantes deverão aparecer antes das ações de cadastro.
- A navegação deverá permanecer consistente em todas as telas.
