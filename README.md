# 💰 Controle Financeiro Pessoal

Este projeto é um sistema simples de controle financeiro desenvolvido em Python.

## 📌 Objetivo

O objetivo principal é auxiliar no controle de gastos, especialmente no uso de cartão de crédito, incluindo:

* Controle de gastos na fatura
* Gerenciamento de compras parceladas
* Simulação de fechamento de fatura

🚀 Em desenvolvimento  
📌 Versão atual: **v0.1**

## 📦 Versão Atual - v0.1 (Controle de Cartão)

Esta versão implementa a base do sistema focada no controle de gastos via cartão de crédito.

### Funcionalidades:
* Adição de gastos no cartão à vista
* Adição de compras parceladas
* Controle de parcelas restantes
* Fechamento de fatura mensal
* Persistência de dados em JSON
* Menu interativo no terminal

👉 Esta versão representa a estrutura inicial do sistema.
